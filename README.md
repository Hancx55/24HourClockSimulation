# 24-Hour Clock Simulation

This project implements a 24-hour digital clock built with logic gates in Logisim. It was developed to further my understanding of the software and basic Computing logic to improve my coursework for the Computer Architecture module at University. This circuit tracks hours, minutes and seconds using registers, logic gates, adders and Hex digit displays.

## Tech Stack:
- Logisim
- Binary

## Features:
- Hours, minutes and seconds counters which click over when their limit is hit (e.g: 59->00 23->00)
- Hex digit displays show a clean visual output in a HH:MM:SS format
- Each counter triggers the next through a carry-out signal ensuring correct progression of a 24 hour clock
- Built upon a 1 tick per second Logism clock

## Skills Gained:
- Strengthened my understanding of core Computer Architecture concepts including registers, counters and control logic
- Designed a system-level digital circuit using modular hardware components
- Ability to structure complex logic
- Developed practical experience with binary, Boolean reasoning and register state management through hands-on implementation
- Applied logic gates to build a reliable multi-stage  digital system

# How To Use:
1. Download/Clone this repository
2. Open the .circ file in Logisim Evolution
3. Enable auto tick in the simulate settings (ctrl + k) or manually click the Logisim clock
